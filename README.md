# Instagram Login Clone

## 📌 Project Overview
This project is a clean and responsive **Instagram Login Page Clone** built using **React with Vite**.  
The goal of this project is to replicate the basic UI of Instagram’s login screen using modern frontend tools.

---

## ✨ Features
- Username / Email input field
- Password input field
- Login button
- Sign-up prompt
- Instagram-like UI design
- Responsive layout

---

## 🛠️ Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS / CSS
- Git & GitHub
